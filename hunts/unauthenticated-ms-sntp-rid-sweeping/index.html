Unauthenticated MS-SNTP RID Sweeping

High severity TLP:CLEAR Research by Huntress Published 20 Nov 2026

Hypothesis

An adversary is performing unauthenticated MS-SNTP RID sweeping against Domain Controllers to harvest password-derived MACs, often preceded by a configuration downgrade to allow legacy MD5 authenticators.

Brief

Why Now

Credential harvesting often relies on authenticated access, but Timeroasting provides a path for an adversary to collect password-derived data before they ever compromise an account. This hunt design builds on the research published by Huntress in Detecting Timeroasting the Hard Way. It addresses the difficulty of finding these attacks in noisy NTP traffic by correlating network volume with specific configuration changes and offensive tool artifacts.

How the Hunt Flows

The hunt first identifies the active Domain Controllers in the environment. It searches for hosts running the Kerberos Key Distribution Center (KDC) service. This scoping step ensures the analyst focuses subsequent high-volume network queries on the correct infrastructure.

Next, the hunt runs a parallel investigation into network activity and process execution. The network query identifies source IPs making hundreds of requests to Domain Controllers over UDP port 123. Simultaneously, a process query looks for known roasting tools like netexec, kerbwolf, or timeroast.py on endpoints. An analyst then weighs these signals; a single source IP generating a massive spike in NTP traffic while running offensive tooling suggests an active sweep.

Finally, the hunt checks the registry configuration of the targeted Domain Controllers. It specifically looks for the SignatureAuthAllowed value set to 0. This setting forces the use of weaker MD5-based authenticators. When a configuration downgrade aligns with a network sweep, it confirms a coordinated effort to harvest and crack credentials.

What the Hunt Cannot See

This hunt relies on connection metadata and endpoint telemetry. It cannot inspect the actual MS-SNTP packet payloads. Without Deep Packet Inspection (DPI), an analyst cannot distinguish between legacy 68-byte authenticators and modern 120-byte extended authenticators. The hunt also faces a visibility gap regarding unmanaged devices. If an adversary performs a sweep from a BYOD laptop or an unmonitored segment, the activity is invisible unless network flow logs cover those client subnets.

Steps

  1. Query, scoping

    Identify Domain Controllers

    Identify hosts running the Kerberos Key Distribution Center (KDC) service, which is unique to Domain Controllers.

    sql, reads hb_service_activity
    SELECT DISTINCT device_hostname, service_name, service_start_nameFROM hb_service_activityWHERE LOWER(service_name) = 'kdc'  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. A list of hostnames acting as Domain Controllers. Silence means no DCs were identified via service logs in the window.

  2. Query, baseline

    Volumetric NTP connection spikes

    Detect high-frequency UDP/123 connections from a single source, characteristic of a RID sweep.

    sql, reads hb_network_connection
    SELECT src_endpoint_ip, device_hostname, COUNT(*) as request_count, SUM(traffic_packets) as total_packets, MIN(time) as first_seen, MAX(time) as last_seenFROM hb_network_connectionWHERE dst_endpoint_port = 123  AND protocol = 'udp'  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')GROUP BY src_endpoint_ip, device_hostnameHAVING request_count > 100ORDER BY request_count DESC

    What a hit looks like. A source IP making hundreds of NTP requests to a DC. Normal time-sync is periodic and low-volume.

  3. Query, detection candidate

    Roasting tool execution

    Find evidence of offensive tools specifically built for Timeroasting and MS-SNTP abuse.

    sql, reads hb_process_activity
    SELECT device_hostname, user_name, process_name, process_cmd_line, timeFROM hb_process_activityWHERE (instr(',' || '{{roasting_tool_names}}' || ',', ',' || LOWER(process_name) || ',') > 0 OR LOWER(process_cmd_line) LIKE '%timeroast%' OR LOWER(process_cmd_line) LIKE '%trustroast%')  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Process execution records for known roasting tools or command lines containing roasting keywords.

  4. Agent triage

    Initial triage of network activity

    Weigh the volumetric network signal against any identified tool executions to confirm a likely roasting attempt.

  5. Query, enrichment

    Registry crypto downgrade

    Detect configuration changes on DCs that allow legacy MD5 authenticators, facilitating easier offline cracking.

    sql, reads hb_registry_activity
    SELECT device_hostname, reg_target, reg_value_data, timeFROM hb_registry_activityWHERE LOWER(reg_target) LIKE '%\w32time\config\signatureauthallowed'  AND reg_value_data = '0'  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Registry values showing SignatureAuthAllowed set to 0. Silence indicates no downgrade was performed or detected.

  6. Agent triage

    Final Timeroasting assessment

    Synthesize the network volume, tool presence, and registry state into a single host-based verdict.

  7. Decision

    Evaluate maliciousness

    Route the hunt based on whether active roasting or configuration tampering was confirmed.

  8. Response action

    Isolate beachhead

    Isolate the host running roasting tools to prevent further credential harvesting or lateral movement.

  9. Analyst task

    Manual analyst review

    Manually verify the findings and investigate any indeterminate cases.

  10. Analyst task

    Close out

    Document the hunt results and record gaps for the platform team.

# Unauthenticated MS-SNTP RID Sweeping

Timeroasting abuses Microsoft's NTP authentication extension (MS-SNTP) to obtain encrypted authenticators for any domain account without prior authentication. The adversary sweeps Relative Identifiers (RIDs) via UDP/123, collecting MACs that can be cracked offline. This hunt identifies the attack by correlating volumetric NTP spikes reaching Domain Controllers with the presence of roasting tools and specific registry downgrades (SignatureAuthAllowed=0) that force the use of weaker MD5-based authenticators. It follows a phased flow: first establishing the DC scope and initial network indicators, then confirming the configuration state of the targets.

## ntp-sweep-volume
<!-- Volumetric NTP connection spikes -->
Detect high-frequency UDP/123 connections from a single source, characteristic of a RID sweep.

```sqlite target=network role=baseline params=(scope_hosts=scope_hosts, lookback_days=lookback_days)
~~~yaml
baseline:
  compare: new_this_window
  window: '{{lookback_days}}d'
expected: A source IP making hundreds of NTP requests to a DC. Normal time-sync is
  periodic and low-volume.
prevalence:
  by: device_hostname
  key:
  - src_endpoint_ip
  rare_below: 5
reads:
- src_endpoint_ip
- device_hostname
- dst_endpoint_port
- protocol
- traffic_packets
- time
silence: not_evidence_of_absence
source: hb_network_connection
verified: dry-run
verified_at: '2026-11-20'
~~~
SELECT src_endpoint_ip, device_hostname, COUNT(*) as request_count, SUM(traffic_packets) as total_packets, MIN(time) as first_seen, MAX(time) as last_seen FROM hb_network_connection WHERE dst_endpoint_port = 123 AND protocol = 'udp' AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY src_endpoint_ip, device_hostname HAVING request_count > 100 ORDER BY request_count DESC
```
