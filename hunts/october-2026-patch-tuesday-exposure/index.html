Brief

Why now

The October 2026 Patch Tuesday release includes 85 critical remote code execution (RCE) vulnerabilities and a Windows Shell 0-day (CVE-2026-96951). As detailed by Microsoft Patch Tuesday for October 2026 — Snort rules and prominent vulnerabilities, the volume of RCEs presents a significant window of opportunity for adversaries to target unpatched Exchange and Windows hosts. This hunt provides a structured path to find exposure and early signs of exploitation while patching remains in progress.

How the hunt flows

The hunt starts by scoping the environment for exposure. The first query joins vulnerability findings with device inventory to list every host missing the critical October 2026 patches. This creates a targeted list of assets where the risk of exploitation is highest.

Next, the hunt stacks process activity on these vulnerable hosts to find rare binaries. An analyst looks for paths or scripts seen on only one to three systems since the patch disclosure. This phase focuses on identifying first-stage payloads or custom tools that differ from the local software baseline.

The final technical phase monitors for high-confidence behavioral indicators of RCE. The query specifically watches for web server processes like w3wp.exe or productivity applications like Excel and Outlook spawning command shells or script interpreters. These parent-child relationships rarely occur during normal operations and often indicate successful exploitation.

An analyst then evaluates the combined results. By correlating missing patches with rare processes or shell execution, the team can classify hosts as exploited or merely exposed. This prioritized list directs remediation efforts to the systems facing active threats.

What this hunt cannot see

This hunt relies on vulnerability scanner data for its initial scoping. If an asset is unmanaged or the scanner misses a host, that system will not appear in the exposure list. Furthermore, exploitation occurring entirely in kernel space or within VBS Enclaves remains invisible to these process-level queries. Those techniques require memory-level tracing and kernel-mode telemetry not covered here.

# October 2026 Patch Tuesday Exposure Hunt

This hunt identifies exposure to the critical remote code execution (RCE) vulnerabilities disclosed in the October 2026 Microsoft Patch Tuesday, including the Windows Shell 0-day (CVE-2026-96951). It follows the exposure flow: first identifying unpatched hosts via vulnerability findings joined with device inventory, then examining rare process activity on those hosts, and finally monitoring for high-confidence behavioral indicators like web servers or productivity applications spawning command shells.

## vulnerability-scoping
<!-- Identify unpatched vulnerable hosts -->
Locate systems where vulnerability scanners have identified missing patches for the critical October 2026 CVEs, joining with device inventory for direct hostname mapping.

```sqlite target=endpoint role=scoping params=(critical_cves=critical_cves)
~~~yaml
expected: Rows identify specific assets by hostname that remain unpatched. Silence
  means no hosts are reporting these specific vulnerabilities.
reads:
- device_uid
- hostname
- cve_uid
- severity
- status
- first_seen
silence: not_evidence_of_absence
source: hb_vulnerability_finding
verified: dry-run
verified_at: '2026-10-14'
~~~
SELECT d.hostname, v.cve_uid, v.severity, v.status, v.first_seen FROM hb_vulnerability_finding v JOIN hb_devices d ON v.device_uid = d.device_uid WHERE instr(',' || '{{critical_cves}}' || ',', ',' || v.cve_uid || ',') > 0 AND v.status != 'suppressed' ORDER BY v.severity_id DESC
```
