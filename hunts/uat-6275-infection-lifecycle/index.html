UAT-6275 Endpoint Infection and Persistence Lifecycle

An adversary has established a foothold using WinRAR path traversal or macro-enabled documents to execute GitHub-hosted PowerShell scripts and persist via custom reverse shells.

Brief

Why Now

Cisco Talos recently detailed UAT-6275 (also known as Silent Lynx), a Kazakhstan-nexus actor targeting government organizations. Their report, "Break the silence: Kazakhstan-nexus UAT-6275 targets CIS government organizations" (https://blog.talosintelligence.com/break-the-silence-kazakhstan-nexus-uat-6275-targets-cis-government-organizations/), describes a sophisticated infection chain using public vulnerabilities and custom shells.

Scoping and Initial Access

The hunt begins by identifying hosts with the CVE-2025-8088 vulnerability. This scoping phase focuses the investigation on systems where the adversary's WinRAR-based delivery method is most likely to succeed.

Parallel Delivery Search

The second phase looks for the delivery of second-stage payloads. The query searches for PowerShell script blocks referencing GitHub domains and correlates this with DNS lookups to known payload hosting infrastructure. This confirms whether a vulnerable host actually attempted to retrieve malicious code.

Triage and Evidence Gathering

An analyst reviews the intersection of vulnerable systems and GitHub-linked script execution. This triage step narrows the fleet to a subset of hosts showing high-confidence delivery signals before proceeding to deeper persistence checks.

Persistence and Custom Shells

The hunt then examines scheduled tasks for references to custom malware families like PickleShell, Chvost, or Laplas. It simultaneously looks for rare processes exhibiting persistent outbound network connections to external IPs. This dual-track approach identifies the actor's persistence mechanism and active command-and-control channels.

Final Synthesis

The final phase combines delivery, persistence, and C2 signals. An analyst evaluates the combined evidence to provide a per-host verdict. This ensures that findings are not just isolated alerts but part of a confirmed intrusion chain.

Blind Spots

This hunt relies on endpoint telemetry. It cannot see activity on unmanaged assets where the WinRAR exploit might still succeed. Additionally, heavily obfuscated PowerShell scripts may be truncated in logs, potentially hiding GitHub URLs from the detection engine.

# UAT-6275 Endpoint Infection and Persistence Lifecycle

This hunt examines the workstation infection lifecycle of the UAT-6275 (Silent Lynx) cluster. It begins by identifying hosts vulnerable to the WinRAR CVE-2025-8088 exploit, then searches for evidence of PowerShell payload retrieval from GitHub. The second phase pivots to look for persistence mechanisms—specifically scheduled tasks referencing custom malware families—and corroborates this with rare outbound network connections indicative of reverse shell C2.

