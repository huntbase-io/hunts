# Post-Exploit Hunt for WordPress wp2shell Critical RCE

### Why this hunt? Rapid7 recently detailed a critical unauthenticated RCE chain in WordPress core, dubbed wp2shell (CVE-2026-63030). This vulnerability allows attackers to execute arbitrary code on the underlying host. This hunt focuses on the post-exploitation behaviors that follow a successful exploit, specifically focusing on how an attacker moves from a web shell to network-wide access. ### The Hypothesis An adversary exploits the WordPress wp2shell vulnerability to gain shell access and then attempts to move laterally through the network via RDP or SSH using credentials compromised from the web server. ### The Hunt Flow The first phase scopes the estate to find vulnerable systems. The hunt queries software inventory to list every host running WordPress versions 6.8.x, 6.9.x, or 7.0.x below the recommended patch levels. This step ensures the analyst focuses on the systems most likely to be targeted. The second phase examines process activity on those identified hosts. The hunt looks for rare instances where a web server process, such as php-fpm or nginx, spawns a shell or common discovery tools like whoami and uname. By stack-counting these events across the fleet, we isolate one-off attacker activity from routine server maintenance. The third phase identifies potential lateral movement. The hunt correlates previous process anomalies with successful RDP or SSH authentications on those same hosts. This pivot identifies if an attacker is using the web server as a beachhead to access other parts of the infrastructure. Finally, an analyst or automated agent triages the results. They evaluate the host's vulnerability status against the observed process and authentication telemetry to provide a final verdict for remediation. ### Blind Spots This hunt relies on endpoint telemetry for confirmation. If a vulnerable WordPress host lacks an endpoint monitoring agent, the hunt can identify the exposure but cannot see the shell activity. Additionally, the lateral movement phase focuses on RDP and SSH; an attacker using proprietary or non-standard protocols for pivoting may remain hidden. ### How to run it This hunt is provided as an open hunt.md playbook. You can import it into Huntbase or any hunt.md-aware runtime to begin searching for wp2shell exploitation and lateral movement across your WordPress environment.
