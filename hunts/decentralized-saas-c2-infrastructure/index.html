Brief

Why This Hunt Matters

The DFIR Report recently published a flash alert regarding The Gentleman Ransomware. The investigation highlights how EtherRAT and TukTuk malware use decentralized infrastructure for command-and-control resolution. These malware families do not rely on static domain names that defenders can easily block. Instead, they use blockchain gateways and legitimate SaaS platforms to store and rotate their configuration data.

How the Hunt Flows

The first phase focuses on scoping via DNS telemetry. The query identifies resolutions for blockchain gateways such as Arweave or Ethereum RPC nodes and SaaS platforms like TryCloudflare. These services lack a business requirement for most enterprise endpoints, making any interaction a candidate for further review.

The second phase applies a prevalence baseline to the initial results. The hunt stacks domain lookups across the entire fleet to isolate rare outliers. By focusing on domains that appear on five or fewer hosts, the analyst removes common background noise and highlights unique infrastructure interactions associated with specific malware instances.

The third phase enriches the findings by correlating network connections with process behavior. The hunt specifically looks for outbound traffic from known abused binaries like node.exe or processes executing from user-writable paths like AppData. This link between the resolution of a decentralized gateway and a suspicious process increases the confidence of the finding.

The final phase uses an automated triage step to evaluate the collected evidence. The logic compares the rarity of the destination against the reputation of the initiating process path. A final verdict identifies hosts that require isolation or manual memory forensics to extract the C2 configuration blob.

Blind Spots

This hunt relies on telemetry that links DNS queries to specific process IDs. If the endpoint sensor does not provide this correlation, an analyst may struggle to distinguish between a user visiting a site in a browser and background malware resolution. Additionally, because these gateways often serve traffic over encrypted channels, the hunt identifies the resolution event but cannot see the actual configuration payload without TLS inspection or host-based memory analysis.

# Decentralized and SaaS C2 Infrastructure

This hunt targets the network infrastructure pattern used by EtherRAT and TukTuk. These malware families use Ethereum and Arweave blockchain gateways to resolve dynamic C2 addresses and use SaaS platforms like Supabase or TryCloudflare for persistent command channels. The hunt identifies rare lookups to these services and correlates them with suspicious processes or non-standard binaries executing on the host.
