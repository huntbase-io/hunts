Brief

Investigating CLOSEDQUORUM Autonomous Activity

Cisco Talos recently published "The Closed Quorum: Inside the first reported autonomous AI C2 implant" (https://blog.talosintelligence.com/the-closed-quorum-inside-the-first-reported-autonomous-ai-c2-implant/), describing a Go-compiled implant that uses LLM providers to decide its next move. This hunt focuses on the endpoint footprint left by these autonomous decisions. The research highlights how the implant coordinates between multiple models to avoid mistakes. Our hunt mirrors this by checking three distinct techniques that represent different implant modules.

How the hunt flows

The hunt begins with a lead query focused on crypto wallet harvesting. It searches for file access events involving known wallet filenames like exodus.wallet or wallet.dat. A hit here identifies a potentially compromised host where the "steal" module is active. The adversary targets wallet data to fund operations, and we look for these reads specifically from processes that do not normally touch user profile data. Next, the hunt fans out to check for fileless code. It identifies processes running without a corresponding binary on disk, targeting the implant's process hollowing and APC injection modules. This query looks for anomalies in standard system processes like svchost.exe or explorer.exe where the "on_disk" flag is false. Simultaneously, the hunt baselines WMI activity across the estate. It stack-counts WMI event subscription commands to find rare permanent consumers created for persistence. This step isolates unique ActiveScriptEventConsumer or CommandLineEventConsumer instances that deviate from the fleet's baseline. We are not just looking for execution; we are looking for the permanent event filters that allow the implant to survive reboots without a registry key. The final phase uses an agent to weigh the combined telemetry. If a host shows overlapping evidence of wallet access, injection, and rare WMI persistence, the agent confirms the presence of an autonomous implant session. An autonomous implant often performs these actions in a quick sequence once the LLM quorum reaches a decision. While a single WMI event might occur in isolation due to system management, the combination of fileless injection with these other indicators is a high-confidence signal.

What the hunt cannot see

This hunt has two primary blind spots. First, it lacks memory visibility. If the implant injects code into a process that terminates before the hunt runs, the activity remains invisible. Second, it cannot see the AI's reasoning. Without TLS inspection of the HTTPS traffic to providers like DeepSeek or Gemini, we cannot view the JSON fields containing the reasoning behind the implant's actions.

  3. WMI event subscription baseline

    Query · baseline

    Stack-count WMI commands to isolate rare permanent event consumers created by the implant's persistence module.

    reads hb_process_activitysql
    SELECT process_cmd_line, COUNT(DISTINCT device_hostname) AS host_count, MIN(time) AS first_seen FROM hb_process_activity WHERE (LOWER(process_name) LIKE '%wmic.exe' OR LOWER(process_name) LIKE '%scrcons.exe') AND (LOWER(process_cmd_line) LIKE '%activescripteventconsumer%' OR LOWER(process_cmd_line) LIKE '%commandlineeventconsumer%') AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY process_cmd_line HAVING host_count <= 5 ORDER BY host_count ASC

    What a hit looks like. A rare WMI command creating a permanent event consumer. Silence confirms no rare WMI persistence was established in the window.

# CLOSEDQUORUM AI Payload Actions

This hunt identifies the endpoint artifacts of CLOSEDQUORUM decisions: specifically, the steal capability targeting crypto wallets, the inject capability using process hollowing or APC injection, and the persist capability using WMI event subscriptions. The hunt starts with a lead query for wallet access to identify potentially compromised hosts, then fans out to detect fileless code and rare WMI persistence commands across the estate. An agent weighs the combined telemetry to confirm the presence of an autonomous implant session.
