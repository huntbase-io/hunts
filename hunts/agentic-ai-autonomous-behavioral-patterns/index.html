Agentic AI Autonomous Behavioral Patterns

High severity TLP:CLEAR Research by Unit 42 Published 25 Nov 2026

Hypothesis

An autonomous AI agent is conducting an intrusion, evidenced by inhuman command velocity, structured section headers in shell output, and chain-of-thought reasoning comments within script telemetry.

Brief

Why now

Attackers now use autonomous AI agents to compress the attack lifecycle. A recent report from Unit 42, Recent Trends and Tactics of Agentic AI Attacks, describes adversaries handing off initial web shell access to AI agents. These agents operate at machine speed, performing reconnaissance and privilege escalation faster than human defenders can typically react. Traditional detections often miss these because the commands themselves may appear standard, but the volume and the reasoning behind them are distinctly non-human.

How the hunt flows

The first phase scopes the environment to identify Linux hosts vulnerable to specific kernel exploits like CVE-2024-1086. The adversary targets these systems for rapid, iterative privilege escalation. The hunt uses the hb_vulnerability_finding surface to prioritize hosts where an agent might attempt to compile custom exploits.

The second phase looks for the physical fingerprints of an AI operator. We query hb_process_activity to find parents launching hundreds of unique child processes in a tight window. Simultaneously, we search hb_script_activity for "chain-of-thought" markers like "thought:" or "reasoning:" and machine-readable section headers that agents use to parse their own progress.

Once the hunt identifies a suspicious velocity or reasoning marker, an analyst triages the host to confirm the agentic footprint. We then pivot to look for follow-on activity. This includes high-volume cloud API discovery calls in hb_cloud_api_activity and network connections to known GSocket or SSH tunneling relays in hb_network_connection.

Finally, the hunt synthesizes these stages into a verdict. If the evidence confirms an autonomous agent, the playbook triggers an isolation action to halt the attack before exfiltration begins.

What the hunt cannot see

This hunt relies on EDR capturing full script contents and high-resolution timestamps. If the telemetry provider truncates large script blocks, we may lose the "reasoning" comments that distinguish an agent from a standard script. Furthermore, if process creation timestamps are rounded to the nearest second, the 1.4-second command gap characteristic of these agents becomes harder to differentiate from fast human activity or legitimate automation frameworks.

  2. Query, baseline

    Inhuman command execution velocity

    Identify hosts where a single parent launches hundreds of unique children in a tight window, indicating automated agent control.

    sql, reads hb_process_activity
    SELECT device_hostname, user_name, parent_process_name, COUNT(*) AS total_commands, COUNT(DISTINCT process_name) AS unique_commands, MIN(time) AS first_seen, MAX(time) AS last_seenFROM hb_process_activityWHERE ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')GROUP BY device_hostname, user_name, parent_process_nameHAVING unique_commands > 100ORDER BY total_commands DESC

    What a hit looks like. Hosts with hundreds of unique commands from a single parent. A median gap analysis by an analyst can confirm the 1.4s velocity mentioned in the report.

  3. Query, detection candidate

    Reasoning comments and section headers in scripts

    Detect scripts containing conversational comments or machine-readable headers used by AI agents to navigate and parse their own results.

    sql, reads hb_script_activity
    SELECT device_hostname, script_type, script_name, script_content, timeFROM hb_script_activityWHERE (LOWER(script_content) LIKE '%===[%' OR LOWER(script_content) LIKE '%thought:%' OR LOWER(script_content) LIKE '%reasoning:%' OR LOWER(script_content) LIKE '%step 1:%' OR instr(',' || '{{ai_script_markers}}' || ',', ',' || LOWER(script_name) || ',') > 0)  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Script contents showing 'chain-of-thought' reasoning or filenames from the ai_script_markers list. These markers are high-fidelity indicators of an autonomous operator.

  4. Agent triage

    Triage early-stage automation

    Weigh the velocity and the AI markers together to determine if an autonomous agent is active on any host.

  5. Query, enrichment

    Follow-on cloud reconnaissance activity

    Identify high-volume cloud API calls indicating the strategic discovery phase directed by the AI agent.

    sql, reads hb_cloud_api_activity
    SELECT actor_user_name, src_endpoint_ip, api_service_name, api_operation, COUNT(*) AS call_countFROM hb_cloud_api_activityWHERE (api_operation LIKE 'List%' OR api_operation LIKE 'Describe%' OR api_operation LIKE 'Get%')  AND time >= datetime('now', '-{{lookback_days}} days')GROUP BY actor_user_name, src_endpoint_ip, api_service_name, api_operationHAVING call_count > 50ORDER BY call_count DESC

    What a hit looks like. High-volume discovery calls from a single IP or user account. These represent the automated mapping of the target environment.

  6. Query, triage

    C2 network connections and protocol tunnels

    Corroborate the automated activity with connections to known campaign IPs or protocol relays.

    What a hit looks like. Connections to the listed campaign IPs. Silence here but hits on earlier stages suggests a rotation of infrastructure.

  7. Agent triage

    Final assessment of the agentic chain

    A final agent evaluates the complete path: from vulnerable hosts to machine-speed execution, reasoning markers, and follow-on pivots.

  8. Decision

    Route on agent verdict

    Direct the hunt to immediate isolation if an agentic intrusion is confirmed.

  9. Response action

    Isolate compromised host

    Immediately isolate hosts under agentic AI control to halt a machine-speed attack lifecycle.

  10. Analyst task

    Analyst forensic review

    Review the reasoning comments and inter-command gaps for confirmed hosts to refine future detections.

  11. Analyst task

    Hunt close-out

    Record findings and document any false positives from benign automation frameworks.

Blind spots

It would answer: Are the reasoning comments captured in full by the EDR? Remediation: Audit script block logging limits and ensure interpreters are fully monitored.

It would answer: Can we reliably distinguish the 1.4s AI gap from 20s human gap? Remediation: Enable high-resolution process creation auditing.

# Agentic AI Autonomous Behavioral Patterns

The phased flow starts by scoping to vulnerable hosts likely to be targeted for kernel exploitation, then pivots to detect the unique behavioral markers of AI-driven execution before hunting for follow-on cloud reconnaissance and protocol tunneling. The adversary gains initial access via web shells and hands off control to an autonomous AI agent that operates at machine speed. The hunt first identifies vulnerable hosts prone to iterative privilege escalation attempts. It then searches for the unmistakable behavioral markers of agentic AI: an inhuman inter-command gap and reasoning comments embedded in shell scripts. The analyst reviews these automated triggers before pivoting to cloud-level discovery and network tunneling to confirm an active intrusion.
