# Hunting for Sensitive Data Staging and Rare Outbound Connections

### The Final Stage of the Pivot 10 10The recent analysis by Unit 42, [Inside the Modern SOC: Defending the Cross-Environment Pivot](https://unit42.paloaltonetworks.com/soc-cross-environment-pivot/), highlights how adversaries move across environments to reach their ultimate goals. Often, those goals involve the collection and removal of sensitive data. While early-stage detection focuses on initial access, this hunt targets the final, high-impact behaviors: data staging and exfiltration. 10 10An adversary stages sensitive information in temporary directories and exfiltrates that data via rare outbound network connections or DNS lookups. 10 10### Phase 1: Identifying Staging 10 10The hunt begins on the endpoint by examining file system activity. The first query searches the `hb_file_activity` surface for the creation of compressed archives, such as ZIP, 7z, or RAR files. It specifically targets user-writable directories like `\Users\Public\`, `\Temp\`, `/tmp/`, and `/dev/shm/`. Adversaries use these locations because they often lack strict write protections and serve as convenient collection points before the data leaves the environment. This step creates a list of candidate hosts and filenames for further investigation. 10 10### Phase 2: Correlating Network and DNS Anomalies 10 10Once the hunt identifies staging activity, it pivots to the network and DNS surfaces in parallel. One path examines outbound network connections to external IP addresses. It applies a prevalence filter to find destinations that appear on only a few hosts across the entire fleet. A connection to a rare external IP address shortly after an archive is created in a temp folder is a strong indicator of exfiltration. 10 10Simultaneously, the hunt looks for behavioral DNS anomalies. It identifies rare domain queries that do not match known local or internal patterns. Adversaries frequently use unique domains or subdomains for command-and-control and data tunneling. Finding a rare domain query on the same host that performed data staging increases the confidence in a malicious verdict. 10 10### Phase 3: Triage and Verdict 10 10An agent reviews the combined evidence from all three surfaces. The triage process looks for process-level links: did the same process that created the archive also initiate the rare network connection? If the agent finds a single host performing all three behaviors, it flags the activity as malicious. This multi-surface correlation allows the hunt to ignore a sysadmin who creates a backup archive but does not send it to an unknown external destination. 10 10### Blind Spots and Limitations 10 10The primary blind spot is the mapping between processes and network sockets. If the endpoint agent cannot definitively link a file-creation process to a network flow, an analyst must manually confirm the timing and parentage. Additionally, encrypted exfiltration via HTTPS or custom protocols hides the specific content and volume of the data transfer, making it difficult to assess the full scope of the theft without TLS inspection. 10 10### How to Run This Hunt 10 10This hunt is packaged as an open `hunt.md` playbook. You can import this file into Huntbase or any runtime that supports the `hunt.md` format.
