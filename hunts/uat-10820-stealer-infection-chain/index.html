UAT-10820 Multi-Stage Stealer Infection Chain

An intruder has infected an endpoint using a WebDAV social engineering chain, followed by the execution of disguised DLLs via rundll32 ordinals and the installation of unauthorized RMM tools for persistence.

Brief

The Context of UAT-10820 Compromise 13; 13;Cisco

Talos recently detailed a multi-stage infection chain in their article, We've got one word for it, and it's usually the wrong one. The report describes an adversary using deceptive social engineering scripts to mount WebDAV shares, which lead to the deployment of the Amatera stealer and persistent remote access tools. This activity involves specific evasion techniques like rundll32 ordinal loading and the use of vulnerable drivers to disable endpoint security. 13; 13;

How the Hunt Flows

13; 13;The hunt begins by filtering the estate for Windows workstations and servers. This scoping ensures the subsequent queries target systems where WebDAV mounting and DLL loading are viable attack vectors. 13; 13;The first analysis phase runs two queries in parallel to catch the infection at the point of execution. The first search scans script activity logs for command blocks that use net use or dav keywords alongside script execution. This targets the specific behavior of users pasting encoded commands to mount remote attacker-controlled shares. The second query baselines rundll32.exe activity across the environment to find rare command lines using ordinal calls (e.g., ,#1) rather than named function exports. This tactic often disguises the loading of malicious payloads like Amatera. 13; 13;The second phase pivots to persistence and defense evasion markers on any hosts identified in the previous step. The hunt searches for NetSupport Manager (client32.exe) and other RMM tools running from unusual, user-writable directories like AppData or Temp. Simultaneously, it inspects kernel driver activity for the loading of known vulnerable drivers. These drivers, such as those from Process Explorer or IObit, are frequently part of Bring Your Own Vulnerable Driver (BYOVD) attacks aimed at terminating security agents. 13; 13;Finally, an automated agent correlates these findings. It connects the early script execution signals to the rare process commands and the eventual RMM persistence. This links the entire intrusion chain into a single verdict for the analyst. 13; 13;

What the Hunt Cannot See

13; 13;This hunt has two primary blind spots. First, it cannot inspect the contents of encrypted WebDAV traffic. If the initial access does not leave clear script telemetry, the hunt relies entirely on the rundll32 and driver-loading signals. Second, it misses stealers that remain only in memory once the initial loader process terminates. Confirming the presence of memory-resident Amatera components requires live memory forensics or specialized memory scanning. 13; 13;

# UAT-10820 Multi-Stage Stealer Infection Chain

This hunt identifies the multi-stage infection pattern of UAT-10820, starting with interactive scripts that mount WebDAV shares or paste base64-encoded commands. It pivots to identify rare rundll32.exe executions using ordinal calls instead of named exports, a tactic used to load the Amatera stealer. The second phase corroborates these leads by hunting for unauthorized NetSupport Manager installations in user-writable paths and the presence of vulnerable drivers used for EDR termination. The phased agent-led analysis connects early-stage access signals to persistent, high-impact indicators.
