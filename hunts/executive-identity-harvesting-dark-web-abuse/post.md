# Hunting for Executive Identity Harvesting and Dark Web Abuse

### The Shift to Identity-as-a-Service The Rapid7 research, Identity-as-a-Service: Uncovering Dark Web Marketplaces Trading Executive SSNs (https://www.rapid7.com/blog/post/tr-identity-as-a-service-dark-web-marketplaces-executive-ssn), highlights a maturing ecosystem where criminals trade stolen Social Security numbers belonging to corporate leadership. Executives are high-value targets because their PII enables high-limit credit fraud and sophisticated account impersonation. This hunt focuses on identifying the activity that feeds these marketplaces. ### The Hypothesis An intruder deploys infostealer malware on a high-profile device to harvest PII and SSNs. The adversary subsequently trades these identities on dark web marketplaces or uses them for account impersonation to gain further access to the organization. ### Scoping the Estate The hunt begins by identifying hosts where executive users sign in. This focuses the investigation on assets most likely to contain high-value sensitive documents. By filtering for leadership usernames across authentication logs, we build a target list of devices for deeper inspection. ### Parallel Harvesting Analysis The second phase runs two concurrent queries. One monitors for non-standard processes—those other than common browsers or PDF readers—accessing files with names containing tax, onboarding, or SSN. The other identifies processes interacting with browser profile data, such as Chrome or Edge login databases. This phase captures the core behavior of infostealers that scrape both local documents and stored web credentials. ### Correlating Infrastructure and Authentication The third phase looks for signs of weaponization. We query DNS logs for traffic to known identity marketplaces and Tor mirrors identified in the source research. Simultaneously, the hunt stacks sign-in locations for executive accounts to find rare IP addresses or new geographic origins. This step distinguishes between a passive infection and an active impersonation event. ### Blind Spots and Limitations Visibility remains the primary challenge. If an executive uses an unmanaged personal device for corporate work, the initial harvesting phase occurs outside the reach of enterprise telemetry. Furthermore, the use of DNS-over-HTTPS (DoH) can hide traffic to marketplaces if the organization relies solely on network-level DNS logs rather than endpoint-level query logging. ### How to Run the Hunt This hunt exists as an open hunt.md playbook. You can import it into Huntbase or any runtime that supports the hunt.md format. Unlike a static detection rule, this playbook pivots between host, network, and authentication surfaces to provide a complete view of the identity theft lifecycle.
