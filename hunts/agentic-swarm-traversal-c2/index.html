Brief

Why This Hunt

The report One breach, please, and make no mistakes by Talos (https://blog.talosintelligence.com/one-breach-please-and-make-no-mistakes/) details how adversaries execute precise, rapid-fire compromises. When an intrusion moves at machine speed using autonomous agents, the time between initial access and impact shrinks. Traditional alerts for isolated events often fail to capture the coordination required for these swarms to operate. We published this hunt to find the collective footprint of agentic traversal and C2 coordination.

How the Hunt Flows

The hunt begins by scoping the environment for unauthorized modifications to Group Policy Objects or sensitive AD containers. The first query targets the hb_entity_management surface to find new or updated GPOs by unexpected service accounts or administrative principals. This identifies the mechanism the adversary uses for internal traversal and persistent access.

Next, the hunt executes a parallel scan of network and endpoint telemetry. One branch monitors the hb_dns_activity surface for high-frequency bursts of queries to a single domain. This identifies the transport layer for agent coordination or command-and-control heartbeats. Simultaneously, a second branch examines the hb_file_activity surface for processes interacting with an unusually large number of distinct files. This detects the rapid data staging or encryption typical of automated impact.

The final phase uses an agent to weigh the evidence. An analyst reviews the temporal overlaps between the GPO changes, the DNS volume, and the file bursts. Isolated administrative work might trigger one of these leads, but the correlation of two or more behaviors on the same host or user account indicates a coordinated intrusion.

Blind Spots

This hunt has specific visibility limits. If the adversary uses DNS-over-HTTPS (DoH) for coordination, the hb_dns_activity surface does not capture the traffic. Additionally, the file activity detection requires 100% EDR coverage. A swarm targeting an unmanaged server segment leaves only the AD audit logs visible, potentially hiding the scale of the exfiltration or encryption phase.

  1. Suspicious GPO and AD Entity Modifications

    Query · scoping

    Identify unauthorized modifications to Group Policy Objects or sensitive AD containers that indicate an agent swarm establishing persistent internal traversal.

    reads hb_entity_managementsql
    SELECT device_hostname, entity_name, actor_user_name, actor_user_uid, attribute_name, attribute_value, time FROM hb_entity_management WHERE activity_id IN (1, 3) AND (LOWER(entity_name) LIKE '%\cn=policies%' OR LOWER(entity_name) LIKE '%\cn=gpo%') AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Rows indicating creation or update of GPO attributes by unexpected service accounts or newly seen administrative principals. Silence suggests no active AD-level persistence was attempted.

  2. Anomalous DNS Query Volume

    Query · baseline

    Detect high-frequency DNS query bursts that indicate agent coordination or C2 heartbeats using DNS as an transport.

    reads hb_dns_activitysql
    SELECT device_hostname, query_hostname, COUNT(*) as query_count, strftime('%Y-%m-%d %H', time) as burst_hour FROM hb_dns_activity WHERE ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY device_hostname, query_hostname, burst_hour HAVING query_count > {{min_dns_hourly}}

    What a hit looks like. A single host querying the same domain over 1000 times in an hour. Low volume suggest the swarm is dormant or using stealthier protocols.

  3. High-Density File Activity Bursts

    Query · detection candidate

    Identify processes interacting with an unusually large number of distinct files in a short window, suggesting exfiltration or encryption.

    reads hb_file_activitysql
    SELECT device_hostname, process_name, COUNT(DISTINCT file_path) as unique_files_touched, strftime('%Y-%m-%d %H', time) as burst_hour FROM hb_file_activity WHERE ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND activity_id IN (1, 3, 4) AND LOWER(process_name) NOT LIKE '%backup%' AND LOWER(process_name) NOT LIKE '%msmpeng%' AND LOWER(process_name) NOT LIKE '%search%' AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY device_hostname, process_name, burst_hour HAVING unique_files_touched > 500

    What a hit looks like. A process touching 500+ unique files in an hour. Excludes common system processes to minimize noise.

# Agentic Swarm Traversal and C2 Coordination

This hunt identifies the footprint of an AI-driven swarm that use automation to traverse networks at machine speed. It looks for the early noisy signs of agentic activity: unauthorized Active Directory policy modifications, followed by a parallel check for anomalous DNS coordination traffic and mass file system interactions typical of data exfiltration or encryption for impact.
