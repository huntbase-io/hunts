Cloud Discovery and Multi-hop Proxy C2

An adversary is using compromised cloud instances to perform resource discovery while masking their command-and-control traffic through multi-hop proxies and long-lived outbound tunnels.

Brief

Background

Cloud assets are frequently repurposed by adversaries as operational relay boxes (ORBs). These instances provide a trusted IP reputation for masking command-and-control (C2) traffic or scanning other environments. Recent research from Elastic Security Labs, Inside Elastic InfoSec's agentic SOC: When to inline your agent's skills for a 5× cost reduction, highlights how automated analysis can handle the high volume of signals generated by complex cloud environments. This hunt applies that logic to the detection of proxy behavior and cloud-plane discovery.

How the Hunt Flows

The hunt begins by scoping the environment to active AWS cloud instances. We establish a baseline of running devices to ensure we are only analyzing the infrastructure relevant to cloud-plane attacks. This step focuses the subsequent queries on high-value ingress and egress points.

Next, the hunt moves into a parallel analysis phase. We look for behavioral network signals, specifically targeting high-volume outbound connections on common proxy ports like 9001, 9050, or 1080. Simultaneously, we stack-count DNS resolutions for rare C2 domains and hidden services (like .onion addresses) that appear on a very small number of hosts across the estate.

Finally, we correlate these network signals with cloud authentication events. By pivoting on the IP addresses identified in the network phase, we look for AWS sign-in attempts from those same IPs. This join allows us to see if a suspected proxy node is also being used to authenticate against the cloud control plane for discovery purposes.

Blind Spots

While this hunt is effective at identifying the 'where' and 'when' of a proxy, it has two primary limitations. First, it relies on authentication sign-in logs rather than full CloudTrail data events. This means we can see the login, but not the specific resources (like S3 buckets or IAM policies) being enumerated. Second, without TLS inspection, we cannot see the payload of the encrypted tunnels; we are relying entirely on volume, port, and duration as behavioral indicators.

    What a hit looks like. A list of hostnames and IPs associated with active AWS instances. Silence suggests no AWS-managed devices are reporting.

  2. Behavioral analysis of long-lived proxy connections

    Query · detection candidate

    Identify instances showing sustained outbound traffic on common proxy ports, indicating a tunnel or relay node.

    reads hb_network_connectionsql
    SELECT device_hostname, src_endpoint_ip, dst_endpoint_ip, dst_endpoint_port, SUM(traffic_bytes) as total_bytes, COUNT(*) as flow_count FROM hb_network_connection WHERE (instr(',' || '{{proxy_ports}}' || ',', ',' || CAST(dst_endpoint_port AS TEXT) || ',') > 0) AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND direction = 'outbound' AND state_kind = 'log' AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY 1, 2, 3, 4 HAVING total_bytes > 5000000 ORDER BY total_bytes DESC

    What a hit looks like. High-volume outbound connections to ports 9001/9050 etc. from scoped AWS instances. Rare counts suggest non-standard behavior.

  3. Stack-count rare C2 and proxy DNS resolutions

    Query · baseline

    Identify hosts resolving known C2 domains or onion-routing domains that are rare in the environment.

    reads hb_dns_activitysql

# Cloud Discovery and Multi-hop Proxy C2

This hunt identifies cloud infrastructure being repurposed as proxy nodes for command-and-control. It begins by identifying active AWS EC2 instances and then searches for behavioral network signals—specifically high-volume, long-lived outbound connections on common proxy ports—emanating from those scoped hosts. Finally, it correlates these network anomalies with AWS authentication events to identify potential cloud control-plane discovery or enumeration.
