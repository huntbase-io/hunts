# UAT-10147 Evasion and Persistence

This hunt targets the secondary phase of the UAT-10147 campaign. After initial web exploitation, the threat actor uses privilege escalation tools like EfsPotato (renamed to prcc1.rar) to disable endpoint protections. They specifically target Windows Defender, adding IIS directories to exclusion lists via PowerShell and the Registry. This hunt identifies those tampering events and correlates them with the creation of masquerading scheduled tasks ('Google Chrome Start') and the provisioning of unauthorized RDP access. By stack-counting unusual executions in paths like C:\ProgramData, we identify the rare staging scripts and payloads characteristic of this adversary's automated workflow.

## scoping-web-servers
<!-- Identify web server assets -->
Focus the hunt on assets running software known to be targeted by UAT-10147, such as IIS, Zimbra, and Telerik components.

```sqlite target=endpoint role=scoping
~~~yaml
expected: A list of hosts hosting web applications. Silence suggests the inventory
  does not identify these specific packages, necessitating a wider host search.
reads:
- device_hostname
- package_name
- package_version
silence: not_evidence_of_absence
source: hb_software_inventory
verified: dry-run
verified_at: '2026-09-09'
~~~
SELECT DISTINCT device_hostname, package_name, package_version FROM hb_software_inventory WHERE LOWER(package_name) LIKE '%iis%' OR LOWER(package_name) LIKE '%apache%' OR LOWER(package_name) LIKE '%nginx%' OR LOWER(package_name) LIKE '%zimbra%' OR LOWER(package_name) LIKE '%telerik%'
```

## defender-tampering-behavior
<!-- Defender exclusion tampering -->
Detect the core evasion tactic: using elevated privileges to exclude IIS directories from Windows Defender scanning.

```sqlite target=endpoint role=detection-candidate params=(lookback_days=lookback_days)
~~~yaml
expected: Command lines modifying Defender path exclusions. This is a high-confidence
  indicator of defense evasion in a web server context.
reads:
- device_hostname
- process_cmd_line
- user_name
- time
silence: not_evidence_of_absence
source: hb_process_activity
verified: dry-run
verified_at: '2026-09-09'
~~~
SELECT device_hostname, process_cmd_line, user_name, time FROM hb_process_activity WHERE ((LOWER(process_cmd_line) LIKE '%add-mppreference%' AND LOWER(process_cmd_line) LIKE '%-exclusionpath%' AND (LOWER(process_cmd_line) LIKE '%inetsrv%' OR LOWER(process_cmd_line) LIKE '%programdata%')) OR (LOWER(process_cmd_line) LIKE '%reg add%' AND LOWER(process_cmd_line) LIKE '%defender\exclusions%')) AND time >= datetime('now', '-{{lookback_days}} days')
```

## rare-programdata-execution
<!-- Rare ProgramData execution -->
Identify rare binaries or scripts executing from C:\ProgramData, which is the observed staging path for UAT-10147 payloads.

```sqlite target=endpoint role=baseline params=(lookback_days=lookback_days)
~~~yaml
baseline:
  compare: first_seen
  window: '{{lookback_days}}d'
expected: Unique or rare batch files or binaries in ProgramData. Silence is evidence
  of absence if the source covers all process launches.
prevalence:
  by: device_hostname
  key:
  - cmd
  rare_below: 3
reads:
- process_cmd_line
- device_hostname
- time
- process_path
silence: evidence_of_absence
source: hb_process_activity
verified: dry-run
verified_at: '2026-09-09'
~~~
SELECT LOWER(process_cmd_line) AS cmd, COUNT(DISTINCT device_hostname) AS hosts, MIN(time) AS first_seen FROM hb_process_activity WHERE (LOWER(process_path) LIKE '%\programdata\%' OR LOWER(process_cmd_line) LIKE '%\programdata\%') AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY 1 HAVING hosts <= 3 ORDER BY hosts ASC
```

## masquerading-tasks
<!-- Masquerading scheduled tasks -->
Detect the 'Google Chrome Start' task or tasks executing from ProgramData, used for persistence.

```sqlite target=endpoint role=triage params=(lookback_days=lookback_days)
~~~yaml
expected: Scheduled tasks using legitimate software names but executing malicious
  scripts or binaries from unusual paths.
reads:
- device_hostname
- job_name
- job_cmd_line
- job_user_name
- time
silence: not_evidence_of_absence
source: hb_scheduled_job

SELECT device_hostname, job_name, job_cmd_line, job_user_name, time FROM hb_scheduled_job WHERE (LOWER(job_name) LIKE '%google%chrome%' OR LOWER(job_cmd_line) LIKE '%\programdata\%') AND time >= datetime('now', '-{{lookback_days}} days')
```

- time
