MacSync Binary Persistence and Application Tampering

An adversary has established long-term persistence on a macOS host by installing a Mach-O RAT via a custom LaunchAgent and is using specialized capture agents to bypass TCC permissions and phish for crypto wallet recovery phrases.

Brief

Why this hunt matters

This hunt cites the Huntress research MacSync Stealer: How a Google Search for Claude Led to a macOS Infostealer (https://www.huntress.com/blog/fake-claude-macsync). The report describes a campaign where users download fake software that drops a persistent Mach-O RAT targeting credentials and crypto assets. This hunt focuses on the post-infection binary stages that established security controls often overlook.

How the hunt flows

The first phase baselines LaunchAgent activity in the user's library directory. The query identifies agents that appear on fewer than three hosts across the fleet. This targets the RAT's persistence mechanism, which often mimics legitimate software updater names but remains unique to the individual victim. Once the analyst identifies lead hosts, the hunt checks for network command and control. It searches for persistent WebSocket connections to known C2 infrastructure on port 8443. This provides a secondary indicator of infection that does not rely on the initial loader's polymorphic file name or hash. The third phase examines process execution for specific TCC-bypass behavior. The hunt targets capture helpers running with the --tcc-only and -o flags. These specific flag combinations are used by the malware to automate screen recording for credential theft and are rarely seen in legitimate software applications. Simultaneously, the hunt searches for file system artifacts created during the exfiltration phase. It looks for the hidden .mpwd credential file and the osalogging.zip archive in temporary directories. These hardcoded file names are strong indicators of successful credential harvesting and staging for theft. The final phase monitors the execution of common crypto wallet applications on the suspected hosts. By correlating the launch of software like MetaMask or Ledger with the previous indicators, the analyst confirms the final stage of the adversary's intent to rotate seeds or steal funds.

Blind Spots

This hunt relies on endpoint telemetry from managed devices and cannot observe activity on unmanaged macOS hosts. While it flags suspicious command-line parameters for screen capture, it cannot confirm if the user granted the TCC permission without access to the Unified Log Facility. Additionally, the TLS-encrypted WebSocket channel prevents the hunt from inspecting the specific commands sent or the volume of data exfiltrated.

Steps

  1. Rare LaunchAgent Persistence

    Query · baseline

    Identify newly created or modified LaunchAgents in user directories that are rare across the fleet, excluding standard system paths.

    reads hb_scheduled_jobsql
    SELECT job_name, job_path, job_cmd_line, device_hostname, COUNT(DISTINCT device_hostname) AS host_count, MIN(time) AS first_seen FROM hb_scheduled_job WHERE job_kind = 'launchd' AND LOWER(job_definition_path) NOT LIKE '/system/library/launchagents/%' AND LOWER(job_definition_path) LIKE '%/library/launchagents/%' AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY job_name, job_path, job_cmd_line, device_hostname HAVING host_count < 3

    What a hit looks like. Rows identify LaunchAgents seen on very few hosts. Legitimate updaters will have high counts, while the MacSync RAT mimics these names on single systems within the user's library folder.

  2. C2 Network Activity

    Query · enrichment

    Detect network connections to the MacSync RAT infrastructure over the designated WebSocket port on the suspected hosts.

    reads hb_network_connectionsql
    SELECT device_hostname, dst_endpoint_ip, dst_endpoint_port, process_name, time FROM hb_network_connection WHERE instr(',' || '{{c2_ips}}' || ',', ',' || dst_endpoint_ip || ',') > 0 AND dst_endpoint_port = {{c2_port}} AND ('{{lead_hosts}}' = '' OR instr(',' || '{{lead_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Any connection to the designated IP and port indicates active command and control by a MacSync RAT.

# MacSync Binary Persistence and Application Tampering

This hunt identifies the post-infection binary stages of the MacSync Stealer. It targets the Mach-O RAT's persistence mechanism in the user's LaunchAgents directory, its WebSocket-based C2 channel, and the behavior of its specialized screen-capture helper. The hunt also examines the execution of common crypto-wallet applications to identify potential trojanization or theft activity. By correlating rare persistence entries with specific TCC-bypass command-line flags and known C2 network patterns, we identify compromised macOS systems that standard signature-based rules miss due to the polymorphic nature of the initial infection loaders. The triage phase links these behaviors with specific exfiltration artifacts like the hidden .mpwd credential store.

## rare-launchagents
<!-- Rare LaunchAgent Persistence -->
Identify newly created or modified LaunchAgents in user directories that are rare across the fleet, excluding standard system paths.

```sqlite target=endpoint role=baseline params=(lookback_days=lookback_days, scope_hosts=scope_hosts)

- job_path
- job_cmd_line
```
