Endpoint Intrusion and Impact Chain

Medium severity TLP:CLEAR Part 2 of 2 Research by Huntress Published 31 Oct 2026

Hypothesis

An intruder has gained a foothold using unauthorized remote management software or encoded scripts and is now attempting to dump credentials and inhibit system recovery.

Brief

The Value of Correlation

The article Reports of SIEM's Death Have Been Greatly Exaggerated (https://www.huntress.com/blog/reports-that-siem-is-dead-are-exaggerated) discusses how security tools must provide context rather than just raw data. This hunt follows that philosophy by connecting disparate signals into a single intrusion narrative. 10

The Hunt Flow

The first phase scopes the environment for remote management (RMM) software. The query targets known tools like ScreenConnect, AnyDesk, and Atera. This step identifies the systems with existing external access capabilities that an adversary can hijack or install for persistence. 10Next, the hunt gathers evidence of an early foothold in parallel. It searches for suspicious PowerShell script blocks containing keywords like VirtualAlloc or ReflectiveLoad and stacks account creation events. The logic highlights accounts created on only one or two hosts. An analyst or agent evaluates these findings to confirm which systems show signs of an unauthorized presence.

The third phase focuses on post-exploitation impact. On the flagged hosts, the hunt looks for processes accessing LSASS memory, which indicates credential dumping. Simultaneously, it checks for commands that delete volume shadow copies using tools like vssadmin or wmic. This specific sequence of events — access followed by destructive impact — separates an active threat from administrative noise. 10Finally, a triage agent correlates the findings from both phases. If a host shows both a suspected foothold and evidence of LSASS access or shadow copy deletion, the hunt directs the analyst to isolate the host and perform a detailed review. 10

Blind Spots

This hunt has specific limitations. An adversary might rename system tools like vssadmin.exe to evade string-match rules on the command line. If process telemetry does not include full auditing of renamed binaries, this activity will be missed. Additionally, many security agents and diagnostic tools regularly access LSASS. Without a solid baseline of approved binaries, these events can create false positives during the triage phase. 10

  2. Query, detection candidate

    Suspicious PowerShell script blocks

    Find script blocks containing keywords associated with memory manipulation or reflective loading.

    sql, reads hb_script_activity

    What a hit looks like. Scripts that attempt to execute code in memory, often bypassing command-line detection.

  3. Query, baseline

    Rare account creations

    Stack-count account creation events across the fleet to find accounts created on only a few hosts.

    sql, reads hb_account_change
    SELECT user_name, COUNT(DISTINCT device_hostname) AS host_count, MIN(time) AS first_seenFROM hb_account_changeWHERE activity_id = 1  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')GROUP BY user_nameHAVING host_count <= 2

    What a hit looks like. New accounts that appear on only 1 or 2 systems, highlighting potential unauthorized persistence.

  4. Agent triage

    Evaluate early foothold signs

    Analyze whether the RMM presence, suspicious scripts, and rare accounts suggest a compromised host.

  5. Query, triage

    LSASS memory access

    Identify processes requesting access to LSASS, which is typical for credential dumping.

    sql, reads hb_resource_activity
    SELECT device_hostname, actor_process_name, object_name, access_mask, timeFROM hb_resource_activityWHERE object_type = 'Process'  AND (LOWER(object_name) LIKE '%\\lsass.exe')  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. An actor process opening a handle to LSASS. Non-system processes in this role are highly suspicious.

  6. Query, enrichment

    Shadow copy deletion

    Detect the use of system tools to delete volume shadow copies, preventing system recovery.

    sql, reads hb_process_activity
    SELECT device_hostname, process_cmd_line, user_name, timeFROM hb_process_activityWHERE (LOWER(process_cmd_line) LIKE '%vssadmin%' AND LOWER(process_cmd_line) LIKE '%delete%' AND LOWER(process_cmd_line) LIKE '%shadow%')  OR (LOWER(process_cmd_line) LIKE '%wmic%' AND LOWER(process_cmd_line) LIKE '%shadowcopy%' AND LOWER(process_cmd_line) LIKE '%delete%')  AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)  AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. Commands used to wipe backups. Silence is evidence of absence for these specific commands.

  7. Agent triage

    Correlate full intrusion chain

    Connect early-stage foothold findings with late-stage impact evidence to confirm a multi-stage intrusion.

  8. Decision

    Route on intrusion verdict

    Direct the response based on the confirmed presence of a multi-stage intrusion.

  9. Response action

    Isolate compromised host

    Sever the adversary's connection and prevent further data destruction.

  10. Analyst task

    Detailed analyst review

    Verify the automated findings and determine the scope of the compromise.

  11. Analyst task

    Hunt close-out

    Document findings and tune sensors if the activity was benign.

# Endpoint Intrusion and Impact Chain

This hunt identifies the transition from a suspicious endpoint foothold to high-impact post-exploitation. It first identifies systems running unauthorized remote management (RMM) tools or experiencing rare account creations. It then pivots to look for follow-on actions like LSASS memory access and volume shadow copy deletion on those same systems. By correlating early-stage persistence with late-stage impact tradecraft, an analyst can distinguish an active intrusion from routine maintenance.
