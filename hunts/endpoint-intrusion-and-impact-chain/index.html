Brief

The Value of Correlation

The article Reports of SIEM's Death Have Been Greatly Exaggerated (https://www.huntress.com/blog/reports-that-siem-is-dead-are-exaggerated) discusses how security tools must provide context rather than just raw data. This hunt follows that philosophy by connecting disparate signals into a single intrusion narrative. 10

The Hunt Flow

The first phase scopes the environment for remote management (RMM) software. The query targets known tools like ScreenConnect, AnyDesk, and Atera. This step identifies the systems with existing external access capabilities that an adversary can hijack or install for persistence. 10Next, the hunt gathers evidence of an early foothold in parallel. It searches for suspicious PowerShell script blocks containing keywords like VirtualAlloc or ReflectiveLoad and stacks account creation events. The logic highlights accounts created on only one or two hosts. An analyst or agent evaluates these findings to confirm which systems show signs of an unauthorized presence.

The third phase focuses on post-exploitation impact. On the flagged hosts, the hunt looks for processes accessing LSASS memory, which indicates credential dumping. Simultaneously, it checks for commands that delete volume shadow copies using tools like vssadmin or wmic. This specific sequence of events — access followed by destructive impact — separates an active threat from administrative noise. 10Finally, a triage agent correlates the findings from both phases. If a host shows both a suspected foothold and evidence of LSASS access or shadow copy deletion, the hunt directs the analyst to isolate the host and perform a detailed review. 10

Blind Spots

This hunt has specific limitations. An adversary might rename system tools like vssadmin.exe to evade string-match rules on the command line. If process telemetry does not include full auditing of renamed binaries, this activity will be missed. Additionally, many security agents and diagnostic tools regularly access LSASS. Without a solid baseline of approved binaries, these events can create false positives during the triage phase. 10

# Endpoint Intrusion and Impact Chain

This hunt identifies the transition from a suspicious endpoint foothold to high-impact post-exploitation. It first identifies systems running unauthorized remote management (RMM) tools or experiencing rare account creations. It then pivots to look for follow-on actions like LSASS memory access and volume shadow copy deletion on those same systems. By correlating early-stage persistence with late-stage impact tradecraft, an analyst can distinguish an active intrusion from routine maintenance.
