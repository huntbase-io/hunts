# Hunting Healthcare Data Leakage and Ransomware Activity

### Why this hunt? Proofpoint reports in Healthcare Cyberattacks Hit Harder, Cost More (https://www.proofpoint.com/us/newsroom/news/healthcare-cyberattacks-hit-harder-cost-more) that the financial and operational impact of intrusions in the healthcare sector is rising. This hunt addresses the dual threat of data exfiltration through modern AI tools and the destructive impact of ransomware on clinical environments. ### Hypothesis Sensitive healthcare data is being leaked via AI chat prompts while ransomware actors prepare or execute high-impact encryption on clinical endpoints, potentially using the same AI interfaces to automate data analysis or extortion. ### How the hunt flows The hunt begins by scoping the environment for AI service interactions. The first query searches the hb_http_activity surface for HTTP POST requests directed at common AI domains like OpenAI, Anthropic, and Gemini. This step identifies which hosts are actively sending data outbound, creating a focused list of systems for deeper inspection. Next, the hunt fans out into two parallel queries to find evidence of impact on those specific hosts. One query monitors the hb_file_activity surface for massive spikes in file creation, deletion, or renaming. It filters for processes that touch more than 500 files in a short window, a behavior typical of ransomware encryption. The second parallel query examines the hb_process_activity surface. It looks for rare binaries or processes running from suspicious locations such as temporary folders or public user directories. This identifies potential ransomware droppers or unauthorized exfiltration tools that may not yet have a known signature. Finally, an agent triages the gathered evidence. It correlates the AI network traffic with the file and process anomalies to determine if a host is compromised. If the analyst finds active encryption or massive data leakage, the hunt provides a direct path to isolate the endpoint and begin incident review. ### Blind spots This hunt cannot see the specific text sent in an AI prompt because the HTTP telemetry only captures the hostname and method. Without TLS termination at a proxy, the presence of actual patient data remains an inference. Additionally, many legacy medical imaging and diagnostic systems do not support modern endpoint agents. These machines may undergo encryption without generating the file or process telemetry this hunt requires. ### How to run it This hunt is an open hunt.md playbook. You can import it into Huntbase or any other hunt.md-aware runtime. It uses standard SQL-based queries and allows for parameter adjustments to include additional AI domains or specific host ranges.
