Thermo Fisher Torrent Suite Path Traversal Exposure

An authenticated intruder is exploiting a path traversal vulnerability (CVE-2026-107777) in Thermo Fisher Torrent Suite Software to exfiltrate sensitive configuration and system files from healthcare servers.

Brief

Vulnerability Context

CISA published advisory ICSMA-26-288-01 detailing a path traversal vulnerability in Thermo Fisher Torrent Suite Software. This software manages sensitive genomic and medical data, making it a high-value target for intruders. The vulnerability, tracked as CVE-2026-107777, allows an authenticated user to access files outside the intended web directory. This hunt provides a structured method to identify vulnerable servers and determine if exploitation occurred.

How the Hunt Flows

The hunt starts by narrowing the scope to relevant assets. The first query uses software inventory data to list every host running Torrent Suite version 5.18 or lower. This prevents the hunt from processing data for patched or irrelevant systems. Next, the hunt baselines authentication activity. Because this vulnerability requires a valid account, the hunt identifies rare successful sign-ins to the vulnerable servers. An analyst looks for accounts logging in from unusual geographies or during non-business hours, as these often precede exploitation. The third phase examines HTTP activity for behavioral indicators. The query searches for dot-dot-slash sequences in URL paths. The hunt specifically flags requests that return a 200 OK status, which suggests the server processed the traversal attempt successfully. The final phase confirms the breach by monitoring file system access. It identifies the web service account—such as apache or nginx—reading sensitive files from a predefined list. When a web process reads /etc/passwd or a .env file, it confirms the adversary successfully bypassed the web root.

Beyond Simple Detection

This is structured as a hunt because simple alerts on traversal strings often produce excessive false positives from vulnerability scanners or administrative scripts. By correlating the software version with rare authentication and the actual file-read event on the host, the hunt provides the context needed to confirm a compromise. It transforms a high-volume signal into a high-fidelity investigation.

Blind Spots and Limitations

This hunt relies on comprehensive HTTP logging. If the environment does not capture full URL strings, unsuccessful traversal probes remain invisible. Additionally, the hunt does not address the initial access vector. If an attacker acquired credentials through phishing, that activity occurs on surfaces like email or proxy logs which this hunt does not include.

  1. Inventory vulnerable Torrent Suite installations

    Query · scoping

    Identify hosts running Thermo Fisher Torrent Suite Software version 5.18 or lower to narrow the hunt scope.

    reads hb_software_inventorysql
    SELECT device_hostname, package_name, package_version, install_path FROM hb_software_inventory WHERE LOWER(package_name) LIKE '%torrent suite%' AND package_version < '5.2'

    What a hit looks like. A list of hosts running versions prior to 5.2. Silence means no vulnerable software is installed or the inventory is out of date.

  2. Rare authentication on Torrent servers

    Query · baseline

    Identify anomalous authenticated access, as the vulnerability requires a valid account for exploitation.

    reads hb_auth_signinsql
    SELECT actor_user_name, device_hostname, src_location_country, src_endpoint_ip, COUNT(*) AS login_count, MIN(time) AS first_login, MAX(time) AS last_login FROM hb_auth_signin WHERE (('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)) AND status_id = 1 AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY actor_user_name, device_hostname, src_location_country, src_endpoint_ip HAVING login_count < 5 ORDER BY login_count ASC

    What a hit looks like. Accounts with very few successful logins to the targeted servers. In healthcare systems, even a single login from an unusual geography is more significant than the raw count.

  3. HTTP path traversal attempts

    Query · detection candidate

    Find HTTP requests containing dot-dot-slash sequences that attempt to break out of the web root.

    reads hb_http_activitysql
    SELECT device_hostname, src_endpoint_ip, url_full, status_code, user_agent, time FROM hb_http_activity WHERE (('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)) AND (instr(LOWER(url_full), '../') > 0 OR instr(LOWER(url_full), '..\') > 0) AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. HTTP requests targeting the Torrent Suite servers that include traversal characters. Requests returning a 200 OK status are highly suspicious as they indicate successful processing.

  4. Sensitive file reads by web service

    Query · enrichment

    Confirm successful traversal by identifying the web service account reading files from the sensitive files list.

    reads hb_file_activitysql
    SELECT device_hostname, actor_user_name, process_name, file_path, time FROM hb_file_activity WHERE (('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)) AND (instr(LOWER(actor_user_name), 'www') > 0 OR instr(LOWER(actor_user_name), 'apache') > 0 OR instr(LOWER(actor_user_name), 'nginx') > 0 OR instr(LOWER(process_name), 'torrent') > 0) AND instr(',' || '{{sensitive_files}}' || ',', ',' || LOWER(file_path) || ',') > 0 AND activity_id = 2 AND time >= datetime('now', '-{{lookback_days}} days')

    What a hit looks like. The web service account or Torrent process reading files that should not be accessible via the application. This confirms successful arbitrary file disclosure.

# Thermo Fisher Torrent Suite Path Traversal Exposure

This hunt identifies servers running vulnerable versions (<= 5.18) of Thermo Fisher Torrent Suite Software and examines them for exploitation. It first scopes the estate using software inventory data, then baselines user authentication to identify rare or anomalous access. Finally, it searches for behavioral indicators: HTTP requests containing traversal sequences and the web service account reading files in sensitive system paths. This multi-surface approach ensures that even if web logs are missing or traversal characters are obfuscated, the downstream file access behavior is captured.

<!-- Inventory vulnerable Torrent Suite installations -->
Identify hosts running Thermo Fisher Torrent Suite Software version 5.18 or lower to narrow the hunt scope.

```sqlite target=endpoint role=scoping
~~~yaml

  software is installed or the inventory is out of date.
reads:
- device_hostname

- package_version
- install_path
silence: not_evidence_of_absence
source: hb_software_inventory

```

## rare-auth-on-torrent-servers
<!-- Rare authentication on Torrent servers -->
Identify anomalous authenticated access, as the vulnerability requires a valid account for exploitation.

```sqlite target=identity role=baseline params=(scope_hosts=scope_hosts, lookback_days=lookback_days)
~~~yaml

  compare: first_seen
  window: '{{lookback_days}}d'
expected: Accounts with very few successful logins to the targeted servers. In healthcare
  systems, even a single login from an unusual geography is more significant than
  the raw count.

  by: device_hostname

  rare_below: 5

- actor_user_name
- device_hostname
- src_location_country
- src_endpoint_ip
- status_id
- time
silence: not_evidence_of_absence

SELECT actor_user_name, device_hostname, src_location_country, src_endpoint_ip, COUNT(*) AS login_count, MIN(time) AS first_login, MAX(time) AS last_login FROM hb_auth_signin WHERE (('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0)) AND status_id = 1 AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY actor_user_name, device_hostname, src_location_country, src_endpoint_ip HAVING login_count < 5 ORDER BY login_count ASC
```
