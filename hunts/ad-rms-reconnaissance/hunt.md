# AD Rights Management Service Reconnaissance

This hunt targets the reconnaissance phase of an AD RMS attack. AD RMS uses SOAP over HTTP/HTTPS for client operations (certification, licensing) and administration. Because the client pipeline endpoints are open to all domain users, an adversary can discover the cluster and its templates before attempting to reach the gated administrative surface. We first identify the servers hosting the RMS role, then parallel-check for SOAP enumeration (specifically 401s on admin paths), rare user access patterns, and DNS discovery of the cluster infrastructure.

```sqlite target=endpoint role=scoping

source: hb_software_inventory

SELECT device_hostname, package_name, package_version, vendor_name FROM hb_software_inventory WHERE (LOWER(package_name) LIKE '%rights management%' OR LOWER(package_name) LIKE '%ad rms%')
```

## soap-enumeration-patterns
<!-- SOAP endpoint enumeration patterns -->
Identify accounts attempting to reach gated administrative endpoints (/admin) or the client pipeline, looking for 401 Unauthorized errors.

```sqlite target=web role=detection-candidate params=(lookback_days=lookback_days, scope_hosts=scope_hosts)
~~~yaml
expected: Requests to /wmcs/admin/ resulting in status_code 401 from users not in
  the RMS service group, or enumeration of the /certification/ and /licensing/ pipelines.
reads:
- device_hostname
- src_endpoint_ip
- actor_user_name
- url_path
- status_code
- user_agent
- time
silence: not_evidence_of_absence
source: hb_http_activity
verified: dry-run
verified_at: '2026-09-18'
~~~
SELECT device_hostname, src_endpoint_ip, actor_user_name, url_path, status_code, user_agent, time FROM hb_http_activity WHERE LOWER(url_path) LIKE '%/wmcs/%' AND ('{{scope_hosts}}' = '' OR instr(',' || '{{scope_hosts}}' || ',', ',' || device_hostname || ',') > 0) AND time >= datetime('now', '-{{lookback_days}} days') ORDER BY time DESC
```

## rare-rms-user-access
<!-- Rare user access to RMS services -->
Baseline user interaction with the RMS cluster to identify outliers performing discovery.

```sqlite target=web role=baseline params=(lookback_days=lookback_days)
~~~yaml
baseline:
  compare: first_seen
  window: '{{lookback_days}}d'
expected: A user account with no history of RMS usage suddenly interacting with RMS
  endpoints on a small number of servers.
prevalence:
  by: device_hostname
  key:
  - actor_user_name
  rare_below: 3
reads:
- actor_user_name
- device_hostname
- url_path
- time
silence: not_evidence_of_absence
source: hb_http_activity
verified: dry-run
verified_at: '2026-09-18'
~~~
SELECT actor_user_name, COUNT(DISTINCT device_hostname) as hosts_hit, COUNT(*) as request_count, MIN(time) as first_seen FROM hb_http_activity WHERE LOWER(url_path) LIKE '%/wmcs/%' AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY actor_user_name HAVING hosts_hit <= 2 ORDER BY hosts_hit ASC
```

## dns-rms-discovery
<!-- DNS discovery of RMS infrastructure -->
Identify hosts attempting to resolve common RMS-related subdomains or service names, which often precedes SOAP enumeration.

```sqlite target=endpoint role=enrichment params=(lookback_days=lookback_days, rms_keywords=rms_keywords)
~~~yaml
expected: DNS resolutions for RMS service names by unexpected user accounts or from
  non-standard workstations.
reads:
- device_hostname
- query_hostname
- actor_user_name
- time
silence: not_evidence_of_absence
source: hb_dns_activity
verified: dry-run
verified_at: '2026-09-18'
~~~
SELECT device_hostname, query_hostname, actor_user_name, COUNT(*) as query_count FROM hb_dns_activity WHERE (instr(',' || '{{rms_keywords}}' || ',', ',' || LOWER(query_hostname) || ',') > 0 OR LOWER(query_hostname) LIKE '%certification%' OR LOWER(query_hostname) LIKE '%licensing%') AND time >= datetime('now', '-{{lookback_days}} days') GROUP BY device_hostname, query_hostname, actor_user_name
```
