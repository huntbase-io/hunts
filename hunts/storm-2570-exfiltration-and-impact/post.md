# Hunting Storm-2570 Exfiltration and Ransomware Impact Tradecraft

### Why now Microsoft recently detailed Storm-2570's consistent tradecraft in 'Beyond the ransomware: Tracking Storm-2570’s consistent tradecraft across deployments' (https://www.microsoft.com/en-us/security/blog/2026/09/24/beyond-ransomware-tracking-storm-2570-consistent-tradecraft-across-deployments/). While their specific ransomware variants change, their pre-impact behaviors—staging and exfiltration—remain predictable. This hunt focuses on the final stages where data leaves the environment and encryption begins. ### The Hypothesis An intruder is exfiltrating staged directories and Active Directory database fragments using synchronization tools before deploying a ransomware payload for mass encryption. ### How the hunt flows The triage phase searches for the execution of common synchronization tools like rclone and s5cmd. It specifically looks for process arguments involving Active Directory fragments (ntds.dit) or batch scripts designed to enable RDP, which the adversary uses to maintain access during the final impact. The second phase runs two queries in parallel to measure the impact. One query attributes outbound network traffic to specific processes by joining endpoint socket states with flow logs, filtering for transfers exceeding 100MB. The other query monitors file system activity for bursts of modifications or renames, identifying processes that touch more than 500 files in a short window. Finally, the hunt synthesizes these signals. A host showing both high-volume data transfer from a synchronization tool and rapid file modification provides a high-confidence indicator of active ransomware. ### What the hunt cannot see This hunt depends on network flow logs to calculate total transfer volumes; without these, the analyst cannot accurately attribute exfiltration size to a process. It also assumes encryption occurs via standard file system APIs. If the adversary uses low-level disk access or custom drivers to bypass the kernel-level file monitor, the burst activity might remain hidden. ### How to run it This hunt is an open hunt.md playbook. You can import it into Huntbase or any runtime compatible with the hunt.md format to automate the correlation of endpoint and network telemetry.
