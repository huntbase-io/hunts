Abuse of Trusted System Binaries for Payload Delivery

An adversary is exploiting internet-facing applications to execute certutil.exe for proxying payload downloads, which are then launched via rare, encoded PowerShell script blocks.

Brief

The Persistence of Living-off-the-Land

Elastic Security Labs discusses the evolution of detection in Why 2026 is the Year to Upgrade to an Agentic AI SOC (https://www.elastic.co/security-labs/blog/why-2026-is-the-year-to-upgrade-to-an-agentic-ai-soc). This hunt focuses on the persistent challenge of Living-off-the-Land (LotL) binaries. Attackers frequently use signed Microsoft tools like certutil.exe to blend in with administrative traffic and bypass perimeter filters.

How the Hunt Flows

The hunt begins on the DNS surface. A query scans for any instance of certutil.exe resolving domains known for command-and-control or payload hosting. This lead query provides a cost-effective way to filter the fleet before committing to more resource-intensive investigations. If the query identifies suspicious resolutions, an agent evaluates the hosts to determine if the activity appears unauthorized.

Once the hunt identifies suspicious hosts, it fans out to search for preceding and succeeding evidence. It looks for successful HTTP responses involving dynamic file extensions like .php, .jsp, or .asp, which suggest a web exploit served as the entry vector. Simultaneously, the hunt baselines PowerShell script activity across the fleet. It isolates encoded script blocks that appear on only a handful of systems, pointing toward unique malicious payloads rather than standard enterprise scripts.

In the final phase, an agent correlates the timelines across the DNS, HTTP, and script surfaces. If a web exploit attempt leads to a certutil download which then triggers an encoded PowerShell block, the agent marks the host for isolation. This multi-surface correlation reduces the false positives typically associated with monitoring individual LolBins.

Visibility and Limitations

The hunt depends on endpoint DNS logging. If a host resolves a malicious domain via local cache, the lead query will not see the activity. Furthermore, the hunt requires PowerShell Script Block Logging to decode and analyze the final execution stage. Without it, the content of the payload remains invisible. Finally, unmanaged servers in the DMZ that lack EDR coverage represent a significant visibility gap where an adversary could stage payloads unmonitored.

# Abuse of Trusted System Binaries for Payload Delivery

This hunt targets the complete sequence of a Living-off-the-Land attack chain. It begins with a cost-effective lead query on DNS resolutions by certutil.exe to known-malicious infrastructure. If the activity is confirmed suspicious, the hunt fans out to identify the preceding web exploit markers and baseline the presence of rare encoded PowerShell scripts across the fleet. An agent then correlates these multi-surface signals to distinguish legitimate administrative activity from an active intrusion.
