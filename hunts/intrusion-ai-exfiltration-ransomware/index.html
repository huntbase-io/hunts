Adversaries are leveraging Node.js-based tools to exfiltrate data to AI platforms like Claude.ai before deploying ransomware to encrypt the environment.

Brief

The recent release of the Elastic Security MCP App highlights how AI-driven operations are becoming standard in modern security workflows. However, this same connectivity provides a novel path for adversaries. Our latest hunt explores the risk of attackers using Node.js-based tools—frequently used for AI integrations—to move laterally and exfiltrate data to AI platforms before a ransomware payload is deployed. This is a behavioral hunt designed to find coordinated activity that individual detection rules would likely miss or alert on too frequently in development environments.

The hypothesis is straightforward: adversaries are leveraging the legitimacy of Node.js environments to blend in with developers. They use these environments to bridge internal data to external AI services like Claude.ai. This provides a functional command-and-control and exfiltration channel that resembles typical API traffic. By the time a traditional ransomware detection triggers, the exfiltration phase is often already complete.

The hunt begins with scoping through the identification of a Node.js cohort. We establish a list of hosts and users actively running node or node.exe to establish a baseline of developer or AI-integrated activity. By narrowing the fleet to this specific group, we reduce the noise inherent in file and network telemetry. We aren't looking for every instance of a network connection, but specifically those originating from the Node.js process within this identified developer cohort.

In the second phase, the hunt pivots into network behavior and lateral movement. We look for outbound connections to specified AI domains and baseline the User-Agent strings used by the cohort. Identifying a rare User-Agent or an unexpected internal network pivot from a Node.js process—especially to other subnets—provides the first indicator of a coordinated effort rather than a developer's routine task. This phase is critical for distinguishing between legitimate automated tools and manual attacker interaction.

The final stage of the hunt correlates this activity with file system signals. We look for a burst of file modifications or renames—indicators of ransomware encryption—on the same hosts that exhibited suspicious Node.js network activity. This multi-surface correlation across process, network, and file events is what moves the activity from unusual to a high-confidence threat. By looking for more than 100 file changes in a short window within the scoped cohort, we filter out common dev-tool file noise.

There are significant blind spots to consider. Without TLS decryption, we can only see the destination and volume of traffic to AI services, not the contents of the payload. An attacker could easily embed sensitive files in encrypted POST requests to Claude.ai. Furthermore, unmanaged devices or shadow development workstations that lack endpoint agents will not appear in our telemetry, allowing an attacker to operate invisibly if they compromise those assets and use them as a pivot point.

This is a hunt, not a detection, because a standalone rule for Node.js network activity would be unmanageable in most engineering-heavy environments. By requiring the presence of the Node.js process, rare network destinations, and high-volume file activity, we provide a structured way to find malicious intrusions while ignoring legitimate development work. It requires an analyst to weigh these multiple behavioral artifacts before declaring an incident.

To run this hunt, use the provided hunt.md playbook. It is designed to be imported into Huntbase or any hunt.md-aware runtime. Once imported, the scoping step will automatically populate the target cohort based on your telemetry, allowing the parallel correlation steps to run against the most relevant hosts.

# Intrusion, AI-Exfiltration, and Ransomware

This hunt targets the complete lifecycle of a multi-stage intrusion involving credential theft, lateral movement, data exfiltration through Node.js (often mimicking or using AI-bridge components), and final impact via ransomware. It uses a focused cohort of hosts running Node.js to reduce noise and correlates behavioral indicators across process, network, and file activity surfaces.
